# Security policy

This repository holds only a catalog file (`.claude-plugin/marketplace.json`) and a small validation script. It contains no plugin code: each plugin is fetched from its own repository, and each of those repositories has its own `SECURITY.md`.

Report a problem with the catalog itself (a wrong source, a plugin entry that points at the wrong repository, a script flaw) privately through this repository's "Report a vulnerability" option under the Security tab, not in a public issue. Problems inside a plugin go to that plugin's repository.

Before installing any plugin from any marketplace, read what it contains: `/plugin` shows a plugin's components, and each repository linked below is public.
